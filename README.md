# Recursion Practice

A collection of C++ exercises focused on **recursion, backtracking, path counting, and combination generation**.

## Description

This repository contains four recursion practice projects:

* **Score Path Counter** — counts ways to reach score `7` using moves of `2` or `3`.
* **Staircase Path Counter** — counts ways to reach position `4` using steps of `1` or `2`.
* **Recursive Combination Generator** — generates combinations of `k` numbers from `1` to `n` while applying custom constraints.
* **Constrained Combination Generator** — generates combinations while preventing consecutive numbers and requiring the first number to be `1` or the last number to be `n`.

## How to Run

Each project contains its own `main.cpp` and can be compiled separately using `g++`.

Example:

```bash
g++ Score-Path-Counter/main.cpp -o score_path_counter
./score_path_counter
```

On Windows:

```bash
score_path_counter.exe
```
